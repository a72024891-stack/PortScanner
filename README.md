# Port Scanner (C#)

This is my first C# pet-project. A simple port scanner with a graphical user interface (Windows Forms).

## Features (Возможности):
- Scans ports in a specified range (from 1 to 10000).
- Shows open ports in green text.
- Asynchronous scanning (the app doesn't freeze).

## How to run (Как запустить):
1. Open the project in Visual Studio.
2. Run the application (F5).
3. Enter an IP address (e.g., 127.0.0.1) and click "Сканировать".

## What I learned (Чему я научился):
- How to work with `TcpClient` in C#.
- How to create a GUI using Windows Forms.
- How to handle asynchronous tasks using `async/await`.
